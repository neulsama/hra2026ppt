# HRA 2026 송년회 HTML 발표

Edge 또는 Chrome에서 `index.html`을 열면 실행됩니다. 폴더를 통째로 받아 압축을 풀어 주세요. 인터넷 연결 없이도 슬라이드, 이미지와 한글 글꼴을 읽을 수 있습니다.

- **`F5` 또는 ▶ 발표 버튼**으로 발표를 시작합니다. 전체화면에서 상단·하단 바가 사라지고, 마우스는 2초 뒤 숨으며, 화면이 꺼지지 않습니다. `Esc`로 끝냅니다.
- 좌우 방향키·`PageUp`/`PageDown`(프레젠터 리모컨)으로 이동하고 `Space`로 장면 큐(정답 공개, 타이머 시작)를 실행합니다.
- `B`(`.`) 검은 화면, `W`(`,`) 흰 화면, 숫자+`Enter` 장면 이동, `H` 전체화면 없이 바만 숨기기(화면 공유용), `?` 단축키 도움말. 한글 입력 상태에서도 동작합니다.
- 화면 공유나 프로젝터 연결 시 `index.html?present`로 열면 처음부터 발표 모드입니다.
- **사회자** 버튼으로 별도 창을 열면 장면별 대사와 진행 큐, 현재 시각, 경과 시간, 장면 이동 목록이 나옵니다. 사회자 창에서도 같은 단축키(B, W, 숫자+Enter)가 무대에 적용되고, 무대를 새로고침해도 자동으로 다시 연결됩니다. 무대 화면을 전체화면으로 띄운 뒤 사회자 창에서 슬라이드 이동, 자막, 정답 공개와 타이머를 제어할 수 있습니다.
- **운영 패널 → 사진과 영상 준비**에서 사진 퀴즈와 활동 영상 자료를 등록합니다. 선택한 미디어는 현재 탭에 유지됩니다.
- 이름, 문제, 사진은 시연 자료입니다. 점수와 내빈 명단은 브라우저에 저장됩니다.
- 고운바탕 Bold는 SIL Open Font License 1.1로 배포합니다. 배포 조건은 [OFL.txt](OFL.txt)를 참고해 주세요.
- 수정 후 점검 도구는 `qa/` 폴더에 있습니다. 발표에는 필요 없습니다. 사용법은 [qa/README.md](qa/README.md)를 참고해 주세요.
